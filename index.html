Distribution OS

Distribution OS is a personal desktop application I use to research independent films. It runs locally on my own computer and stores its data in a local database — it is not a website, not a product, and is not available to anyone else.

It uses the TMDb API to look up metadata for a small number of candidate films at a time: runtime, country, language, genre, cast and streaming availability. Results are cached locally rather than re-requested.

This product uses the TMDB API but is not endorsed or certified by TMDB. Information courtesy of IMDb (https://www.imdb.com). Used with permission.
